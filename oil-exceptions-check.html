OIL Log Exceptions Check

Cross-checks Exceptions against the 4 OIL/BMR logs, adds newly-missing items to the tracking sheet, and flags vanished holds.

How to use: Refresh the source Exceptions sheet in Smartsheet first, then paste your API token below, confirm the Source Start Date matches the earliest date you paste in, and click Run Check. New missing exceptions are added to the tracking sheet with Status = HOLD — start your 24-hour hold from there. Previously-tracked HOLD rows that disappeared from the source get a note appended, never deleted. Run once per business day.

Step 1 — Smartsheet API Token

Not verified
Stored locally in your browser. Shared token — get it from Rebecca if you don't have one.

Step 2 — Source Start Date

Set this to the earliest date you paste into the source Exceptions sheet. Source rows and tracked HOLD rows dated before it are ignored — earlier items are never flagged as vanished. Historical dedup still spans everything, so nothing gets re-added. Saved locally in your browser.

Step 3 — Run the Check

Reads the Exceptions sheet and all 4 destination logs, computes what's missing and what's vanished, and writes the results straight to the tracking sheet.
